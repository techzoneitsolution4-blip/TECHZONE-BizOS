# TECHZONE BizOS V2.0 — Phase Gates

1. Work on one roadmap step at a time.
2. Inspect existing files before changing them.
3. Implement, run tests, fix errors and verify expected results.
4. Do not mark a step DONE until verification succeeds.
5. Do not begin the next phase until the user explicitly approves DONE.
6. Never commit secrets or expose .env.local values.
7. Never trust a client-supplied tenant ID without server-side authorization.
8. OTP values must not be stored as raw database values.
9. Scaffolded modules are not production-ready integrations.
10. Preserve unrelated user changes and review Git status before commits.
